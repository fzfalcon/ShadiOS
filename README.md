# ShadiOS

PlayStation 4 Emulation for iOS

Open-source • Experimental • iPhone & iPad

Our mission: Port the stable Windows shadPS4 codebase to iOS, starting with your iPhone 13.

Next steps:

1. Create the GitHub repository `ShadiOS`.
2. Inspect the stable shadPS4 source and identify Windows-only dependencies.
3. Build a minimal iOS prototype.
4. Gradually work toward running PS4 games.

One important note: ShadiOS will be our independent project based on shadPS4, with appropriate upstream attribution and license compliance.

Let's build it! 🚀
